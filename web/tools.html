本棚を更新する方法

貸出状況は自動で更新されますが、本の一覧（ブクログの本棚）は、本を追加・状況を変えたときに、この手順で書き出します。ブクログは、GitHubのサーバーからの自動アクセスを受け付けないため、ふだん使っているブラウザで書き出します。1〜2分で終わります。

1. 最初に1回だけ：ブックマークを作る

下のボタンを、ブラウザのブックマークバーにドラッグしてください。

本棚を書き出す

ドラッグできない場合：新しいブックマークを作り、名前を「本棚を書き出す」、URL欄に下のコードを貼り付けてください。

2. 本棚を更新するたびに

  1. ブクログの自分の本棚を開く
  2. ブックマーク「本棚を書き出す」をクリック → shelf.json がダウンロードされる
  3. GitHubの data フォルダを開き、「Add file」→「Upload files」で shelf.json をドラッグし、「Commit changes」を押す
  4. 1〜2分後、自動で貸出状況の取得が走り、このサイトに反映される（Actionsタブで進行を確認できます）
