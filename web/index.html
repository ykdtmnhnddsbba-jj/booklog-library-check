貸出状況を今すぐ最新にしたい

画面右上の「貸出状況を最新に」を押すと、この瞬間の貸出状況を図書館のデータから取り直します（約1分）。初回だけ、カーリルのAPIキーの入力が必要です。キーはこの端末のブラウザに保存されます。「☁ 感想の同期」を済ませていれば、自分のGoogleドライブにも保存され、他の端末では入力不要になります（公開ページやGitHubには載りません）。

本を追加する（ブクログに登録する前でもOK）

右上の「＋ 本を追加」から、ISBNか書名で本を探して追加できます。追加した本は「読みたい」として一覧に並び、図書館の所蔵・貸出状況もすぐ調べます（APIキーが必要です）。追加した本は、この端末のブラウザに保存されます。「☁ 感想の同期」を済ませておくと、スマホとPCで共有されます。

ブクログには自動では登録されません。カードの「ブクログで登録 ↗」から登録できます。登録して本棚を書き出し直すと、同じ本は自動で「ブクログの本」に切り替わります。

本棚（ブクログ）を更新したあと、最新の一覧にしたい

本を追加したり、読書状況を変えたりしたあとは、本の一覧を書き出し直す必要があります。Claudeに頼むのがいちばん簡単です。

Claudeに本棚の更新を頼む ↗

  1. 上のボタンを押すと、依頼文が入力された状態でClaudeが開きます
  2. そのまま送信します（デスクトップアプリを開いておくと、Claudeが自分でブクログを読み込めます）
  3. 数分後、この一覧に反映されます
依頼文を見る・コピーする（リンクで入力されない場合）

自分でやる場合（ブックマーク方式）

  1. 最初に1回だけ：下の「本棚を書き出す」を、ブックマークバーにドラッグして登録する
    本棚を書き出す
  2. ブクログの自分の本棚を開き、登録したブックマークをクリック → shelf.json が保存される
  3. GitHubの data フォルダで「Add file → Upload files」から shelf.json をアップロードして「Commit changes」
  4. 1〜2分後に、貸出状況の取得が自動で走り、この一覧に反映される
ドラッグできない場合：ブックマークのURL欄に貼るコード

感想メモのバックアップ

感想は、まずこの端末のブラウザに保存され、サイトの公開データには載りません。画面上部の「☁ 感想の同期」を押してGoogleにログインすると、自分のGoogleドライブ（booklog-notes.json）にも保存され、スマホとPCで同じ感想が見られます。同期後は、書くたびに自動で保存されます。テスト運用のため、約7日ごとに「要再接続」が出たらもう一度押してください。

念のため、ファイルでの書き出し・読み込みも使えます。

貸出状況は1日1回、自動で更新されます。
