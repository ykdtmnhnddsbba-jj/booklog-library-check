貸出状況を今すぐ最新にしたい

画面右上の「貸出状況を最新に」を押すと、この瞬間の貸出状況を図書館のデータから取り直します（約1分）。初回だけ、カーリルのAPIキーの入力が必要です。キーはこの端末のブラウザにだけ保存されます。

本棚（ブクログ）を更新したあと、最新の一覧にしたい

本を追加したり、読書状況を変えたりしたあとは、本の一覧を書き出し直す必要があります。Claudeに頼むのがいちばん簡単です。

Claudeに本棚の更新を頼む ↗

  1. 上のボタンを押すと、依頼文が入力された状態でClaudeが開きます
  2. そのまま送信します（デスクトップアプリを開いておくと、Claudeが自分でブクログを読み込めます）
  3. 数分後、この一覧に反映されます
依頼文を見る・コピーする（リンクで入力されない場合）

自分でやる場合（ブックマーク方式）

  1. 最初に1回だけ：下の「本棚を書き出す」を、ブックマークバーにドラッグして登録する
    本棚を書き出す
  2. ブクログの自分の本棚を開き、登録したブックマークをクリック → shelf.json が保存される
  3. GitHubの data フォルダで「Add file → Upload files」から shelf.json をアップロードして「Commit changes」
  4. 1〜2分後に、貸出状況の取得が自動で走り、この一覧に反映される
ドラッグできない場合：ブックマークのURL欄に貼るコード

貸出状況は1日1回、自動で更新されます。
